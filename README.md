# Frauen.com — A Velsci Initiative

A secure, accessible single-page web platform designed for female career empowerment and postpartum support.

## How to Run & Deploy via GitHub Pages

1. Create a new repository on GitHub named `frauera-website`.
2. Push `index.html`, `style.css`, `app.js`, and `README.md` to the main branch.
3. In GitHub, go to **Settings > Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch** and select `main` branch `/ (root)`.
5. Save. Your platform will be live at `https://<your-username>.github.io/frauera-website/`.
